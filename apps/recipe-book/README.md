# recipe-book

育てるレシピ帳（仮称）。YouTube・クックパッド・AI で見つけたレシピを集め、作るたびに感想とアレンジを残して、自分のレシピに育てていきます。Gemini や ChatGPT とのつなぎ方（コピー・共有、自分の Google ドライブへの書き出し、Gemini からの直接の操作）は要件定義にまとめてあり、MVP を使ってみてから進めます。

| 場所 | 中身 |
|------|------|
| [`docs/`](docs/) | 要件定義（`requirements.md`） |
| [`android/`](android/) | Android 版の実装（Kotlin + Jetpack Compose + SQLDelight）。動かし方・構成は [`android/README.md`](android/README.md) |
