# recipe-book

育てるレシピ帳（仮称）。YouTube・クックパッド・AI で見つけたレシピを集め、作るたびに感想とアレンジを残して、自分のレシピに育てていきます。Gemini や ChatGPT とは、コピー・共有と、自分の Google ドライブへの書き出しでつなぎます。Gemini からは、会話の中でレシピの保存・記録・修正ができるようにする予定です（Google の Connected Apps と Android の AppFunctions）。
